# CodeAlpha_LanguageTranslator

This is a simple Language Translator web application built using Python and Flask.  
It allows users to translate text from one language to another easily.

## 💡 Features
- Translate text between multiple languages
- Simple and user-friendly interface
- Fast response
- Supports basic language conversion

## 🛠 Technologies Used
- Python
- Flask
- HTML/CSS
- (Optional: API like Google Translate / NLP library if used)

## 🚀 How to Run
1. Install required libraries:
   pip install flask

2. Run the application:
   python app.py

3. Open browser and go to:
   http://127.0.0.1:5000

## 📌 Example
Input: Hello  
Output: Bonjour (French)

## 📂 Project Structure
- app.py → Main Flask backend
- templates/ → HTML frontend files
